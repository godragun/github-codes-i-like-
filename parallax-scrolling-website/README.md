# Parallax Scrolling Website
## [Watch it on youtube](https://youtu.be/JrU6bsuNU7Y)
### Parallax Scrolling Website

## Run locally

1. Open this folder in VS Code.
2. Open `index.html`.
3. Start Live Server.
4. Visit `http://127.0.0.1:5500/parallax-scrolling-website/index.html` (or the URL shown by Live Server).

## Notes

- This project is plain HTML, CSS, and JavaScript. No `npm install` is required.
- Asset paths are set to work from subfolder URLs (for example, `/parallax-scrolling-website/index.html`) and direct local hosting.

- Parallax Scrolling Animation Using HTML CSS JAVASCRIPT
- Includes CSS animations.
- Includes parallax animation.
- Developed first with the Mobile First methodology, then for desktop.
- Compatible with all mobile devices and with a beautiful and pleasant user interface.
